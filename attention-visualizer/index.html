02 · THE CORE IDEA

Query, Key, and Value

Query (Q): what this token is looking for.

Key (K): what each token offers for matching.

Value (V): the information each token contributes.

scoreᵢⱼ = (qᵢ · kⱼ) / √dₖ
αᵢⱼ = softmaxⱼ(scoreᵢⱼ)
contextᵢ = Σⱼ αᵢⱼ vⱼ

The demo uses small illustrative vectors and deterministic scores to make the math visible. It is not a trained language model's attention output.

07 · LEARN THE DIFFERENCE

Self-attention vs cross-attention

Self-attention

Queries, keys, and values come from the same sequence. Tokens can combine information from other tokens in that sequence.

Cross-attention

Queries come from one sequence and keys/values from another, such as a decoder attending to encoder outputs.

Multi-head attention

Several attention heads learn different projection spaces and can capture different relationships in parallel.

Masking

A causal mask prevents a token from attending to future tokens during autoregressive generation.

Learning note: this is a simplified self-attention illustration with toy vectors. Real Transformer layers learn Q, K, and V projection matrices during training.
