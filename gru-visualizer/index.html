02 · GRU AT A GLANCE

Two gates, one hidden state

The reset gate rₜ controls how much previous state helps build a candidate. The update gate zₜ controls the balance between old state and candidate state.

rₜ = σ(Wᵣxₜ + Uᵣhₜ₋₁ + bᵣ)
zₜ = σ(W𝓏xₜ + U𝓏hₜ₋₁ + b𝓏)
h̃ₜ = tanh(Wₕxₜ + Uₕ(rₜ ⊙ hₜ₋₁) + bₕ)
hₜ = (1 − zₜ)hₜ₋₁ + zₜh̃ₜ

This page uses a simplified one-number example, not trained model weights. Some libraries use the opposite convention for the update-gate equation.

06 · BUILD INTUITION

GRU vs RNN vs LSTM

ModelHow it carries informationGatesKey idea
Simple RNNOne hidden state is updated at every step.NoneSimple, but can struggle with long-range dependencies.
GRUOne hidden state with gated updates.Reset + updateCombines gating and memory in a compact cell.
LSTMSeparate cell state and hidden state.Forget + input + output (and candidate)More explicit control over long-term cell memory.

GRU often has fewer parameters than a comparable LSTM, but which performs better depends on the data, task, and model setup.
