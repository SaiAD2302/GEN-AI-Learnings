03 / THE KEY IDEA: TWO TYPES OF MEMORY

Watch both values change
Cell state Cₜ — long pathway

The main memory carried through the sequence. The forget gate controls what old cell information remains; the input gate controls how much new candidate information is written.

Cₜ = [0, 0]
Hidden state hₜ — exposed signal

The current output-like representation. LSTM makes it from the cell state after applying tanh and the output gate. It is also passed to the next time step.

hₜ = [0, 0]
Think of the cell state as a running notebook, and the gates as learned controls on editing that notebook. This is an analogy: each memory is a vector of numbers, not a literal sentence or a separate storage box for every word.

08 / THE FOUR STEPS INSIDE AN LSTM

The same operation repeats for every word
1

Forget gate

Looks at the current word and previous hidden state. A value near 0 reduces old cell information; a value near 1 retains more.

2

Input gate + candidate

The input gate decides how much to write. The candidate proposes new content, with values between −1 and 1.

3

Update cell state

Multiply old memory by the forget gate, then add the gated candidate: Cₜ = fₜ ⊙ Cₜ₋₁ + iₜ ⊙ gₜ.

4

Output gate

Apply tanh to the updated cell state and let the output gate control what becomes the new hidden state.

09 / RNN VS LSTM

Why add gates?

Vanilla RNN

hₜ = tanh(Wₓxₜ + Wₕhₜ₋₁ + b)
  • Updates a hidden state at each time step.
  • Old information must travel through repeated hidden-state updates.
  • Can struggle to learn long-range dependencies due to vanishing/exploding gradients.
Open the RNN Explorer →

LSTM

Cₜ = fₜ⊙Cₜ₋₁ + iₜ⊙gₜ
hₜ = oₜ⊙tanh(Cₜ)
  • Keeps both cell state C and hidden state h.
  • Learned gates regulate forgetting, writing and exposing information.
  • Designed to make learning longer-term dependencies easier; it does not guarantee perfect memory.

This is a transparent educational simulation, not a trained language model. Word vectors and gate weights are fixed illustrative values. A trained LSTM learns its embedding and gate weights from data. The two displayed hidden units are a small example; real LSTMs can have many more units.
