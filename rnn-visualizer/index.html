05 / THE RNN EQUATION

hₜ = tanh(Wₓxₜ + Wₕhₜ₋₁ + b)

Input signal + previous memory + bias → activation → new memory.

The same weight matrices are shared across all time steps. This is what makes the cell recurrent.

08 / NOTATION GLOSSARY

What every symbol means
tTime-step number. In this demo, each word is one step.
xₜNumeric input vector representing the current word.
hₜ₋₁Hidden state from the previous word; initially [0, 0, 0, 0].
hₜNew hidden state after processing the current word.
WₓInput-weight matrix: determines how the word vector affects neurons.
WₕRecurrent-weight matrix: determines how previous memory affects neurons.
bBias added to the weighted signals. Fixed for this teaching demo.
zₜPre-activation sum before tanh: Wₓxₜ + Wₕhₜ₋₁ + b.
tanhActivation function that squashes values between −1 and +1.
hᵢThe activation value of hidden neuron i.
EmbeddingReal NLP systems commonly map tokens to learned vectors. Our encoder is illustrative.
yₜOutput at a time step. The output nodes shown here are illustrative, not trained predictions.

09 / THE FOUR STEPS OF AN RNN

1

Read the current word

Turn the current token into numeric features xₜ. Neural networks calculate with numbers, not raw text.

2

Bring forward memory

Take the previous hidden state hₜ₋₁. It is all zeros before the first word, then it carries forward.

3

Combine and activate

Multiply input and memory by their weights, add bias, then apply tanh to each hidden neuron.

4

Pass memory onward

The new hₜ becomes hₜ₋₁ for the next word. Repeat until the sentence ends.

Why “recurrent”? Because the hidden state is fed back into the same cell at the next time step. Longer sentences mean more time steps, not more hidden neurons.
