05 / HOW TO READ THIS

Each word becomes a numeric input vector. The hidden neurons combine the current input with the previous hidden state, apply tanh, and pass the new state to the next word. Click any neuron to inspect its calculation.
hₜ = tanh(Wₓ xₜ + Wₕ hₜ₋₁ + b)
Teaching demo: illustrative deterministic weights, not a trained language model. Neurons do not inherently correspond to specific words or emotions.
