05 · WHAT A TRANSFORMER BLOCK CONTAINS

Inside one encoder-style block

Multi-head attention

Several attention heads use different learned projections to capture different relationships between tokens.

Residual + normalization

A skip connection adds the input back, while normalization helps stabilize the layer's activations.

Feed-forward network

A small neural network transforms each token representation independently after attention has mixed context.

Attention(Q,K,V) = softmax(QKᵀ / √dₖ)V
Block: x → Attention → Add & Norm → Feed-forward → Add & Norm

Decoder-only language models typically use causal masked self-attention. The original encoder-decoder Transformer also uses encoder-decoder cross-attention in its decoder.

06 · ENCODER VS DECODER

Two common Transformer designs

Encoder-only

Builds contextual representations from input text. Commonly used for classification and understanding tasks.

Decoder-only

Predicts the next token using causal attention. Commonly used by generative language models.

Encoder-decoder

An encoder processes the source; a decoder generates output while attending to the source representations.

Learning note: the pipeline and probability bars use a small illustrative simulation. Real Transformer weights and next-token probabilities are learned from data.
